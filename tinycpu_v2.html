    Bits 15–12 select the operation. Other bits mean different things depending on the opcode. Unused bits must be zero. Registers are unsigned 16-bit values (arithmetic wraps at 65,536). Immediate values: 0–1023. RAM addresses: 0–63. Division truncates toward zero.

    Model limits: TinyCPU is a deliberately invented teaching ISA, not a real processor. RAM is word-addressed; every word is 16 bits. It has no disk, operating system, cache, pipeline, or separate instruction memory. This is intentional.
